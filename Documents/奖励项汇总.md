# 奖励项汇总（截至 2026-02-02）

## 主要来源
- 配置：`legged_gym/legged_gym/envs/g1/g1_mimic_distill_config.py`
  - `G1MimicPrivCfg.rewards`（教师/特权）
  - `G1MimicStuRLCfg.rewards`（学生）
- 实现：`legged_gym/legged_gym/envs/base/humanoid_mimic.py`
- 额外实现：`legged_gym/legged_gym/envs/g1/g1_mimic_distill.py`
- 调用机制：`legged_gym/legged_gym/envs/base/legged_robot.py`（按非零 `scales` 自动注册）

## 当前未启用（scale 为 0 或未定义）
- `alive`（在 `HumanoidCharCfg.rewards.scales` 中定义，但被 G1 配置覆盖）
- `collision`、`orientation`、`feet_height`、`waist_dof_acc`、`waist_dof_vel`、`ankle_action` 等：存在实现/注释但未在 `scales` 启用

## 相关参数（会影响已启用奖励项的行为）
- `max_contact_force`：用于 `feet_contact_forces`
- `soft_torque_limit`、`torque_safety_limit`：用于扭矩限制相关惩罚
- `feet_air_time_target`：用于 `feet_air_time`
- `feet_height_target`：当前未启用 `feet_height`，但参数已配置

## 备注
- 奖励函数通过 `legged_robot.py::_prepare_reward_function` 自动注册：只要在 `cfg.rewards.scales` 中非零就会生效。
- 教师与学生配置的奖励项与系数目前一致。
